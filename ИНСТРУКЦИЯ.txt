  ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ VIRTUAL TRY-ON СКРИПТА
═══════════════════════════════════════════════════════════════

📁 СТРУКТУРА ПАПОК:
───────────────────────────────────────────────────────────────
virtual_try_on/
├── input/
│   ├── person/      ← Сюда кладите фотографии моделей
│   └── product/     ← Сюда кладите фотографии одежды
├── output/          ← Сюда будут сохраняться результаты
└── [файлы скрипта]

═══════════════════════════════════════════════════════════════
🔧 ЧТО НУЖНО СДЕЛАТЬ ПЕРЕД ЗАПУСКОМ:
═══════════════════════════════════════════════════════════════

1. УСТАНОВИТЬ ЗАВИСИМОСТИ:
   ───────────────────────────────────────────────────────────
   pip install -r requirements.txt
   
   Или если используете uv:
   uv pip install -r requirements.txt

2. УСТАНОВИТЬ GOOGLE CLOUD SDK:
   ───────────────────────────────────────────────────────────
   - Скачайте с: https://cloud.google.com/sdk/docs/install
   - Установите SDK
   - Авторизуйтесь командой:
     gcloud auth login

3. СОЗДАТЬ ФАЙЛ .env:
   ───────────────────────────────────────────────────────────
   Создайте файл .env в папке virtual_try_on/ со следующим содержимым:
   
   GOOGLE_CLOUD_PROJECT_ID=ваш-project-id
   GOOGLE_CLOUD_REGION=us-central1
   
   Остальные параметры опциональны (можно не указывать, будут значения по умолчанию):
   
   BASE_STEPS=32
   SAMPLE_COUNT=1
   ADD_WATERMARK=true
   PERSON_GENERATION=allow_adult
   SAFETY_SETTING=block_medium_and_above
   OUTPUT_MIME_TYPE=image/png
   COMPRESSION_QUALITY=75

4. ПОМЕСТИТЬ ИЗОБРАЖЕНИЯ:
   ───────────────────────────────────────────────────────────
   - Фотографии моделей → input/person/
   - Фотографии одежды → input/product/
   
   Поддерживаемые форматы: JPG, JPEG, PNG, BMP, WEBP

═══════════════════════════════════════════════════════════════
▶️  КАК ЗАПУСТИТЬ:
═══════════════════════════════════════════════════════════════

1. Откройте терминал в папке virtual_try_on/
2. Запустите:
   
   python main.py
   
   Или через uv:
   uv run python main.py

3. Скрипт автоматически:
   - Найдет все изображения в папках input/
   - Создаст все возможные комбинации (модель + одежда)
   - Отправит запросы к API
   - Сохранит результаты в папку output/

═══════════════════════════════════════════════════════════════
📋 ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (.env):
═══════════════════════════════════════════════════════════════

ОБЯЗАТЕЛЬНЫЕ:
─────────────
GOOGLE_CLOUD_PROJECT_ID  - ID вашего проекта в Google Cloud
                          (найдите в консоли Google Cloud)

ОПЦИОНАЛЬНЫЕ:
─────────────
GOOGLE_CLOUD_REGION      - Регион (по умолчанию: us-central1)
BASE_STEPS               - Качество генерации, больше = лучше качество, но дольше
                          (по умолчанию: 32)
SAMPLE_COUNT             - Сколько изображений генерировать на каждую пару
                          (от 1 до 4, по умолчанию: 1)
ADD_WATERMARK            - Добавлять невидимый водяной знак
                          (true/false, по умолчанию: true)
PERSON_GENERATION        - Разрешение генерации людей:
                          - dont_allow: запретить людей/лица
                          - allow_adult: только взрослые (по умолчанию)
                          - allow_all: все возрасты
SAFETY_SETTING           - Уровень фильтрации безопасности:
                          - block_low_and_above: самый строгий
                          - block_medium_and_above: средний (по умолчанию)
                          - block_only_high: слабый
                          - block_none: почти не блокирует (требует разрешения)
OUTPUT_MIME_TYPE         - Формат результата:
                          - image/png (по умолчанию)
                          - image/jpeg
COMPRESSION_QUALITY      - Качество сжатия для JPEG (0-100, по умолчанию: 75)
STORAGE_URI              - Путь в Cloud Storage для сохранения
                          (например: gs://bucket-name/path/)
SEED                     - Случайное зерно для воспроизводимости
                          (работает только если ADD_WATERMARK=false)

═══════════════════════════════════════════════════════════════
⚠️  ВАЖНО:
═══════════════════════════════════════════════════════════════

1. Убедитесь, что вы авторизованы через gcloud:
   gcloud auth login

2. Убедитесь, что у вашего проекта включен API Vertex AI

3. Скрипт создаст все комбинации:
   - Если 1 модель + 1 одежда = 1 результат
   - Если 2 модели + 3 одежды = 6 результатов (2×3)

4. Результаты сохраняются с уникальными именами:
   [номер]_[модель]_[одежда]_[вариант]_[дата-время].[расширение]

5. Обработка может занять время (зависит от BASE_STEPS и количества пар)
