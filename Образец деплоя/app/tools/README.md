## Инструменты для агентов

Эта папка содержит все инструменты, которые вызываются стадийными агентами. Соблюдай те же принципы при добавлении новых модулей.

### Структура и стандарты
- Каждый инструмент — отдельная подпапка: `app/tools/<tool_name>/tool.py`.
- В подпапке обязателен `__init__.py`, который экспортирует публичные функции/классы через `__all__`.
- Общие сервисы и вспомогательные компоненты складываем в `app/tools/shared/`. Если добавляешь новый сервис, объяви его в `shared/__init__.py`.
- Корневой `app/tools/__init__.py` оставляем минимальным (делает каталог пакетом).
- Код держим модульным: логика в `logic.py`, внешняя оболочка — в `tool.py`.

### Создание нового инструмента
1. Создай подпапку `app/tools/<tool_name>/`.
2. Добавь `tool.py`:
   - импортируй `tool` из `langchain_core.tools`;
   - определи `pydantic`-схему (`BaseModel`) для входных данных, если инструмент принимает аргументы;
   - декорируй функцию `@tool` (или `@tool(args_schema=...)`);
   - внутри функции используй сервисы из `app/tools/shared`.
3. Создай `__init__.py` в новой папке и экспортируй публичную функцию, например:
   ```python
   from app.tools.example.tool import example_tool

   __all__ = ["example_tool"]
   ```
4. **ВАЖНО:** Зарегистрируй инструмент в реестре.

   Открой файл `app/tools/registry.py` и добавь импорт и регистрацию инструмента в метод `_load_tools()`:

   ```python
   from app.tools.example import example_tool
   
   # В методе _load_tools() добавь инструмент в список:
   tools_list = [
       ...
       example_tool,
   ]
   ```

   После регистрации инструмент автоматически появится в эдиторе для тестирования.

5. Если нужен переиспользуемый сервис (загрузчик данных, клиент API), размести его в `app/tools/shared/` и обязательно обнови `shared/__init__.py`.

### Регистрация инструмента в агенте
1. Импортируй функцию инструмента в нужном агенте:  
   `from app.tools.example import example_tool`.
2. Передай её в список `tools` при создании `create_react_agent`:
   ```python
   agent = create_react_agent(
       model=llm,
       tools=[example_tool, ...],
       prompt=...,
   )
   ```
3. Обнови документацию агента (prompt) при необходимости, чтобы описать, когда использовать инструмент.

### Проверка
- Запусти `python -c "from app.tools.example import example_tool"`, чтобы убедиться, что импорты работают.
- Прогоняй линтер/тесты после добавления нового инструмента.
